# Введение в C++
## Язык программирования C++

***Язык программирования C++ - высокоуровневый, компилируемый, язык программирования общего назначения, со статической типизацией.***
Своими корнями он уходит в язык C, который был разработан в 1969-1973 гг. в компании Bell Labs программистом Деннисом Ритчи.

В начале 1980-х годов Датский программист Бьерн Страуструп, работал в компании Bell Labs, разработал C++, как расширение к языку С.
Фактически в начале С++ просто дополнял язык С некоторыми возможностями ООП. Изначально язык назывался "С с классами".

***С++ - компилируемый язык значит, что компилятор транслирует исходный код на С++ в исполняемый файл, который содержит набор машинных инструкций.***


### Основные компиляторы:
- g++ 
- clang
- Компилятор от Microsoft

### Состав компилятора g++:
1. Cpp - препроцессор
2. As - ассемблер
3. G++ - сам компилятор
4. Id - линкер

### А зачем компилировать исходные файлы?
Исходный C++ файл - всего лишь код, но его не возможно запустить как программу или библиотеку, поэтому каждый исходный файл, нужно скомпелировать в исполняемый.<br>

### Этапы компиляции:
1. Препроцессинг - макропроцессор, который преобразовывает программу, для дальнейшего компилирования. На данной стадии происходит работа с препроцессорными директивами.
Например: препроцессинг (# include, убирает комментарий)
2. Компиляция - преобразование в ассемблерный код. Это промежуточный шаг, между высокоуровневом языке и машинным кодом.
3. Ассемблирование - перевод ассемблерного кода в машинный.
   Объектный файл - созданный ассемблером промежуточный файл, хранящий кусок кода.
   Этот кусок машинного кода, ещё не связанный с другими кусками машинного кода - Объектом кода.
4. Компоновка
   Компоновщик (Линкер) - связывает все объектные файлы и библиотеки в единый исполняемый файл, который мы можем пропустить
5. Загрузка
