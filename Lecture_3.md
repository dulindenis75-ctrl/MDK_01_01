# Тема: Векторы и строки

***Вектор и строка - важный базовый контейнер стандартной библиотеки C++. Они хранят свои элементы в непрерывном фрагменте памяти. Оба этих контейнера предоставляют доступ к элементам по индексу и позволяют эффективно добавлять новые элементы в конце.***


**Контейнер - динамический массив, обеспечивающий быстрое добавление новых элементов в конец и меняющий свой размер при необходимости.**


Рассмотрим пример программы, которая заполняет вектор элементами и печатает их через пробел:

1. #include <iostream><br>
2. #include <vector><br>
3. <br>
4. int main() {<br>
5.    std::vector<int> data = {1, 2, 3, 4, 5};<br>
6.    for (int elem : data) {<br>
7.  std::cout << elem << " ";<br>
8.    }<br>
9.    std::cout << "\n";<br>
10. }<br>


Здесь мы инициализируем вектор через список инициализации, в котором элементы перечислены через запятую. Другой способ инициализации вектора — указать число элементов и (при необходимости) образец элемента:

1. #include <string><br>
2. #include <vector><br>
3. <br>
4. int main() {<br>
5.    std::vector<std::string> v1;  // пустой вектор строк<br>
6.    std::vector<std::string> v2(5);  // вектор из пяти пустых строк<br>
7.    std::vector<std::string> v3(5, "hello");  // вектор из пяти строк "hello"<br>
8. }<br>


## Обращение к элементам

Иногда удобнее работать с индексами. Вектор хранит элементы в памяти последовательно, поэтому по индексу элемента можно быстро найти его положение в памяти. Индексация начинается с нуля:

1. std::vector<int> data = {1, 2, 3, 4, 5};<br>
2. int a = data[0];  // начальный элемент вектора<br>
3. int b = data[4];  // последний элемент вектора (в нём пять элементов)<br>
4. data[2] = -3;  // меняем элемент 3 на -3<br>

Чтобы узнать общее количество элементов в векторе, можно воспользоваться функцией ***size***:

1. std::cout << data.size() << "\n";<br>

Встроенные валидаторы замедляют программу: предполагается, что программист пишет правильный код и уверен, что индекс ***i*** в выражении ***data[i]*** неотрицателен и удовлетворяет условию ***i < data.size()***. В этом случае они ему не нужны.


Если вам не хочется делать много лишних проверок, а в корректности индекса вы не уверены, то можно использовать функцию ***at***:

1. std::vector<int> data = {1, 2, 3, 4, 5};<br>
2. std::cout << data[42] << "\n";  // неопределённое поведение: может произойти всё что угодно<br>
3. std::cout << data.at(0) << "\n";  // напечатается 1<br>
4. std::cout << data.at(42) << "\n";  // произойдёт исключение std::out_of_range — его можно будет перехватить и обработать<br>

Рассмотрим функции вектора ***front*** и ***back***, которые возвращают его первый и последний элемент без использования индексов:

1. std::vector<int> data = {1, 2, 3, 4, 5};<br>
2. std::cout << data.front() << "\n";  // то же, что data[0]<br>
3. std::cout << data.back() << "\n";  // то же, что data[data.size() - 1]<br>

***<u>Важно!!! Вызов этих функций на пустом векторе приведёт к неопределённому поведению.<u>***


Для проверки вектора на пустоту вместо сравнения ***data.size() == 0*** принято использовать функцию empty, которая возвращает логическое значение:

1. if (!data.empty()) {<br>
2.    // вектор не пуст, с ним можно работать<br>
3. }<br>

## Итерация по индексам

Индексы и Контейнеры в коде пишется в виде: ***std::vector<T>::size_type***.

Итерацию по элементам ***data*** с помощью индексов можно записать так:

1. for (size_t i = 0; i != data.size(); ++i) {<br>
2.    std::cout << data[i] << " ";<br>
3. }<br>

Код, проверяющий дубликаты в Векторе:

1. for (std::int64_t i = 0; i < std::size(data) - 1; ++i) {<br>
2.    if (data[i] == data[i + 1]) {<br>
3.    std::cout << "Duplicate value: " << data[i] << "\n";<br>
4.    }<br>
5. }<br>


## Добавление и удаление элементов

В вектор можно эффективно добавлять элементы в конец и удалять их с конца. Для этого существуют функции ***push_back и pop_back***:

1. #include <iostream><br>
2. #include <vector><br>
3. <br>
4. int main() {<br>
5.    int x;<br>
6.    std::vector<int> data;<br>
7.    while (std::cin >> x) {  // читаем числа, пока не закончится ввод<br>
8.    data.push_back(x);  // добавляем очередное число в вектор<br>
9.    }<br>
10.    while (!data.empty() && data.back() == 0) {<br>
11.    // Пока вектор не пуст и последний элемент равен нулю<br>
12.    data.pop_back();  // удаляем этот нулевой элемент<br>
13.    }<br>
14. }<br>


## Резерв памяти

Реаллокация - довольно дорогая процедура, направленная на доказательство того, что новый и старый блоки отличаются по размеру в два раза, то амортизированная сложность добавления будет константой **(ну, зато оптимизированно, а Габен не может уже 3-ий десяток оптимизировать CS2)**.

Текущий резерв вектора можно узнать с помощью функции capacity (не путайте её с функцией ***size***).

А вот так это выглядит:<br>

Рассмотрим программу, в которой в вектор последовательно добавляются элементы и после каждого шага печатается размер и резерв:

1. #include <iostream><br>
2. #include <vector><br>
3. <br>
4. int main() {<br>
5.    std::vector<int> data = {1, 2};<br>
6.    std::cout << data.size() << "\t" << data.capacity() << "\n";<br>
7.    data.push_back(3);<br>
8.    std::cout << data.size() << "\t" << data.capacity() << "\n";<br>
9.    data.push_back(4);<br>
10.    std::cout << data.size() << "\t" << data.capacity() << "\n";<br>
11.    data.push_back(5);<br>
12.    std::cout << data.size() << "\t" << data.capacity() << "\n";<br>
13. }<br>


Видно, что размер вектора увеличивается на единицу, а резерв удваивается после исчерпания. Так, при добавлении четвёрки используется имеющаяся в резерве память, а при добавлении тройки и пятёрки происходит реаллокация.

Иногда требуется заполнить вектор элементами, причём число элементов известно заранее. В таком случае можно сразу зарезервировать нужный размер памяти с помощью функции reserve, чтобы при добавлении элементов не происходили реаллокации. Пусть, например, нам сначала задаётся число слов, а потом сами эти слова, и нам требуется сложить их в вектор:

1. #include <iostream><br>
2. #include <string><br>
3. #include <vector><br>
4. <br>
5. int main() {<br>
6.    std::vector<std::string> words;<br>
7.    size_t words_count;<br>
8.    std::cin >> words_count;<br>
9.    // Размер вектора остаётся нулевым, меняется только резерв:<br>
10.    words.reserve(words_count);<br>
11.    for (size_t i = 0; i != words_count; ++i) {<br>
12.    std::string word;<br>
13.    std::cin >> word;<br>
14.    // Все добавления будут дешёвыми, без реаллокаций:<br>
15.    words.push_back(word);<br>
16.    }<br>
17. }<br>


Функцию reserve не следует путать с функцией ***resize***, которая меняет количество элементов в векторе. Если аргумент функции ***resize*** меньше текущего размера, то лишние элементы в конце вектора удаляются:

1. #include <vector><br>
2. <br>
3. int main() {<br>
4.    std::vector<int> data = {1, 2, 3, 4, 5};<br>
5.    data.reserve(10);  // поменяли резерв, но размер вектора остался равным пяти<br>
6.    data.resize(3);  // удалили последние элементы 4 и 5<br>
7.    data.resize(6);  // получили вектор 1, 2, 3, 0, 0, 0<br>
8. }<br>


## Многомерные векторы

Воспользуемся вектором векторов, чтобы сохранить матрицу (таблицу) целых чисел. Пусть на вход программы сначала поступают число строк и число столбцов матрицы, а потом — сами элементы построчно:

1. #include <iostream><br>
2. #include <vector><br>
3. <br>
4. int main() {<br>
5.    size_t m, n;<br>
6.    std::cin >> m >> n;  // число строк и столбцов<br>
7.    // создаём матрицу matrix из m строк, каждая из которых — вектор из n нулей<br>
8.    std::vector<std::vector<int>> matrix(m, std::vector<int>(n));<br>
9.    for (size_t i = 0; i != m; ++i) {<br>
10.    for (size_t j = 0; j != n; ++j) {<br>
11.    std::cin >> matrix[i][j];<br>
12.    }<br>
13.    }<br>
14.    // напечатаем матрицу, выводя элементы через табуляцию<br>
15.    for (size_t i = 0; i != m; ++i) {<br>
16.    for (size_t j = 0; j != n; ++j) {<br>
20.    std::cout << matrix[i][j] << "\t";<br>
21.    }<br>
22.    std::cout << "\n";<br>
23.    }<br>
24. }<br>


## Сортировка вектора

Сортировка вектора осуществляется с помощью алгоритма сортировки ***Introsot***:

1. #include <algorithm><br>
2. #include <vector><br>
3. <br>
4. int main() {<br>
5.    std::vector<int> data = {3, 1, 4, 1, 5, 9, 2, 6};<br>
6.    // Сортировка диапазона вектора от начала до конца<br>
7.    std::sort(data.begin(), data.end());<br>
8.    // получим вектор 1, 1, 2, 3, 4, 5, 6, 9<br>
9. }<br>

Для сортировки по убыванию можно передать на вход обратные итераторы ***rbegin()*** и ***rend()***, представляющие элементы вектора в перевёрнутом порядке:

1. std::sort(data.rbegin(), data.rend());  // 9, 6, 5, 4, 3, 2, 1, 1<br>


В C++20 доступен более элегантный способ сортировки через ***std::ranges::sort***:

1. #include <algorithm><br>
2. #include <vector><br>
3. <br>
4. int main() {<br>
5.    std::vector<int> data = {3, 1, 4, 1, 5, 9, 2, 6};<br>
6.    std::ranges::sort(data);  // можно передать сам вектор, а не его диапазоны<br>
7. }<br>


## Строки

Контейнер ***std::string*** можно рассматривать как особый случай вектора символов ***std::vector<char>***, имеющий набор дополнительных функций. В частности, у строки есть все те же рассмотренные нами функции, что и у вектора (например, ***pop_back*** или ***resize***):

1. #include <iostream><br>
2. #include <string><br>
3. <br>
4. int main() {<br>
5.    std::string s = "Some string";<br>
6.    // приписывание символов и строк<br>
7.    s += ' ';  // добавляем отдельный символ в конец, это аналог push_back<br>
8.    s += "functions";  // добавляем строку в конец<br>
9.    std::cout << s << "\n";  // Some string functions<br>
10.    // выделение подстроки<br>
11.    // подстрока "string" из 6 символов начиная с 5-й позиции<br>
12.    std::string sub1 = s.substr(5, 6);<br>
13.    // подстрока "functions" с 12-й позиции и до конца<br>
14.    std::string sub2 = s.substr(12);<br>
15.    // поиск символа или подстроки<br>
16.    size_t pos1 = s.find(' ');  // позиция первого пробела, в данном случае 4<br>
17.    size_t pos2 = s.find(' ', pos1 + 1);  // позиция следующего пробела (11)<br>
18.    size_t pos3 = s.find("str");  // вернётся 5<br>
19.    size_t pos4 = s.find("#");  // вернётся std::string::npos<br>
20. }<br>


Вставку, замену и удаление подстрок можно сделать через указание индекса начала и длины подстроки:

1. #include <iostream><br>
2. #include <string><br>
3. <br>
4. int main() {<br>
5.    std::string s = "Some string functions";<br>
6.    // вставка подстроки<br>
7.    s.insert(5, "std::");<br>
8.    std::cout << s << "\n";  // Some std::string functions<br>
9.    // замена указанного диапазона на новую подстроку<br>
10.    s.replace(0, 4, "Special");<br>
11.    std::cout << s << "\n";  // Special std::string functions<br>
12.    // удаление подстроки<br>
13.    s.erase(8, 5);  // Special string functions<br>
14. }<br>


В **C++20** появились удобные функции ***starts_with*** и ***ends_with*** для проверки префикса или суффикса строк:

1. #include <iostream><br>
2. #include <string><br>
3. <br>
4. int main() {<br>
5.    std::string phrase;<br>
6.    std::getline(std::cin, phrase);<br>
7.    if (phrase.starts_with("hello")) {<br>
8.    std::cout << "Greeting\n";<br>
9.    }<br>
10.    if (phrase.ends_with("bye")) {<br>
11.    std::cout << "Farewell\n";<br>
12.    }<br>
13. }<br>
